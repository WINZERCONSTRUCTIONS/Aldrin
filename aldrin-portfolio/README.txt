PREVIEW LOCALLY

DEPLOY TO VERCEL (FREE)
1. Go to https://vercel.com/new
2. Sign in or create a Vercel account.
3. Choose the option to deploy a project, or import a Git repository.
4. To use the folder directly, first create a GitHub repository and upload the contents of this folder, then import that repository in Vercel.
5. Framework preset: Other. Build command: leave blank. Output directory: ./
6. Deploy. Vercel will provide your public https://....vercel.app URL.

No third-party analytics, tracking, or external form service is included. Google Fonts are loaded online; the site otherwise works as a static website.
